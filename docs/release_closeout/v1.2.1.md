## Closed incident

One third-party Windows environment exposed the absence of IANA timezone data
in stable v1.2.0. The public-safe reproduction was
`ZoneInfoNotFoundError` for `Asia/Tokyo`, followed by
`ACTIVITIES_NORMALIZATION_FAILED`. A manual `tzdata` installation restored the
tracked Synthetic Run-All.

v1.2.1 closes that incident by declaring `tzdata` conditionally on Windows,
adding the safe `TIMEZONE_DATA_UNAVAILABLE` diagnostic, adding PowerShell
onboarding, and validating Windows package/runtime paths in CI.

## Post-publication physical Windows evidence

A clean Production PyPI v1.2.1 installation on one maintainer-owned physical
Windows environment automatically installed `tzdata 2026.3` with
`Required-by: garmin-running-data-normalizer`. `Asia/Tokyo` resolved and the
tracked Synthetic Run-All completed with `PASS_WITH_WARNINGS`, exit 0,
Activities detected=1 / processed=1, and `run_summary.json` present.

No manual `pip install tzdata`, local `pip install .`, or editable installation
was used. The repository supplied only the public synthetic fixture.

This evidence is intentionally bounded. It does not establish compatibility
with every Windows version or environment.

## Windows validation workflow policy

Future physical Windows release validation separates source preparation from
Windows runtime execution:

1. On macOS, clone or fetch the repository, check out the exact reviewed tag or
   commit, verify the tag and clean worktree, and prepare the folder to copy.
2. Copy that prepared folder to the Windows validation machine.
3. On Windows, start from `Set-Location` in the copied folder, create a clean
   virtual environment, install from the approved package index or artifact,
   and use only the tracked synthetic fixture.
4. Do not include `git clone`, `git fetch`, `git checkout`, or `git pull` in
   ordinary Windows runtime-validation steps. A separately scoped Windows Git
   validation may use those commands when Git behavior itself is the subject.
5. Record package version, dependency resolution, timezone resolution, command
   status, exit code, safe counts, and completion-marker presence. Do not
   retain usernames, host identifiers, private paths, screenshots, or personal
   Garmin data.

## Immutable boundaries

or authorize a future release. The v1.2.1 tag, GitHub Release, TestPyPI files,
and Production PyPI files remain immutable. Any future publication requires a
