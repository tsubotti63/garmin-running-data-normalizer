## Closed scope

v1.3 closes the Performance Metrics Release scope with 17 normalized datasets
and 212 documented fields. It adds Hill Score, Endurance Score, Race
Prediction, Sleep, UDS, Acute Training Load, Training Readiness, VO2Max, HRV
analysis reference, and limited Training History outputs. Snapshot policies,
Output Experience, deterministic QA, and relationship guidance cover each
stable dataset.

The six pre-existing explicit relationships remain unchanged. New
Wellness/Metrics datasets are not Activity facts and do not gain a direct
Activity relationship. Same-day comparison remains context-only where the
documentation permits it.
