Product-owned public entry points, adds Public Product State validation, and
updates Platform Alignment validation for the approved Product/ACP ownership
model.

dataset, schema, stable key, output path, Snapshot policy, relationship
contract, exit code, or privacy boundary. The v1.3.0 Wellness/Metrics contract
remains unchanged.
