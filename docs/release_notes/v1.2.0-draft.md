# v1.2.0 Release Notes — Draft

Status: Unreleased implementation draft. This document does not authorize a
tag, GitHub Release, TestPyPI upload, or Production PyPI upload.

## Snapshot Accumulation and Canonical Merge Foundation

This release is planned to add an account-bounded, private local Snapshot
lifecycle while preserving the existing v1.1.1 one-shot Run-All behavior.

### Planned additions

- Immutable registration of explicitly confirmed complete Garmin Exports.
- Content-addressed preservation of files and validated archive members.
- Chronological ordering from timezone-aware observation metadata, including
  historical middle insertion and content-idempotent repeat registration.
- Versioned dataset merge policy with `missing_is_not_delete`.
- Previous-only retention, new/reappeared/changed reporting, field-level
  provenance, null/empty review holds, and fail-closed conflicts.
- Cumulative unique FIT materialization followed by full parsing with the
  current stable key and relationship contracts.
- Additive `snapshot` CLI commands and lifecycle evidence in Snapshot Run-All
  output.

### Compatibility

The existing `run-all --input ... --output ...` command and its fixed v1.1
output remain unchanged. Snapshot mode adds lifecycle paths only when explicitly
selected.

### Privacy

Snapshot Stores, approved inputs, and full outputs are private local data.
Public tests and examples are synthetic. No private Snapshot path, row,
identifier, filename, or raw hash is included in this release draft.

### Remaining release-candidate gates

- Full synthetic, static, privacy, package, and installed-flow validation.
- Four-Snapshot private/local validation with Human-confirmed metadata.
- Unit Review and Target Project Core Review.
- Separate Human authorization for any tag, Release, or package-index upload.
