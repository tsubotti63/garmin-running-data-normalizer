# Garmin Running Data Normalizer v1.3.3

These are the final release notes for the v1.3.3 Sleep contract restoration.
Version `1.3.3` was published on 2026-08-13 JST as the annotated tag, the latest
[GitHub Release](https://github.com/tsubotti63/garmin-running-data-normalizer/releases/tag/v1.3.3),
and the verified
[Production PyPI distribution](https://pypi.org/project/garmin-running-data-normalizer/1.3.3/).
The frozen release source is
`cf7e44c18d77adda4c908207361e6f6f5f2b682c`.

## Fixed

- Restored the source-backed `sleep_duration_minutes_ex_awake` contract:
  observed finite deep/light/REM stages are summed when present.
- Preserved missing stages as missing. Awake time and window-minus-awake are
  never used, and all-stage absence falls back only to the approved direct
  aliases when they agree.
- Made conflicting direct aliases fail closed rather than selecting a first or
  latest value.
- Separated review-required counts from excluded-record evidence in daily
  metric audits and Run-All family results.

## Compatibility

- No dataset or field was added. The 17-dataset, 212-field inventory, `sleep_day`
  grain, stable key, nullable number shape, and context-only Activity guidance
  remain unchanged.
- Available Sleep rows may be compared as same-day context. `needs_review` and
  excluded rows are not eligible for Activity context joins.
- Exact output and semantic digests change for inputs whose Sleep duration is
  restored; v1.3.2 Release/PyPI artifacts remain immutable.

## Validation boundary

Focused and full local validation, the public Synthetic Run-All, one private
one-shot, four representative real-data orders, and the private 24-order
matrix have passed for this release source. The overall Run-All status may
remain `PARTIAL_SUCCESS` / exit 0 at the existing FIT boundary.
