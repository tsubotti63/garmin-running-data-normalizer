# Garmin Running Data Normalizer v1.7.1

These are the release notes for the v1.7.1 Snapshot metrics fix release.
Version `1.7.1` was published from the release-ready main source after the
v1.7.1 tag, GitHub Release, and Production PyPI publication gates. The current
stable release is v2.0.0.

## Fixed

- `snapshot run-all` now normalizes the Hill Score, Endurance Score, and VO2Max
  rows of a Snapshot Store. `snapshot build-input` merges these rows into
  `snapshot_HillScore.json`, `snapshot_EnduranceScore.json`, and
  `snapshot_vo2max.json`, but from v1.3.0 through v1.7.0 Run-All did not
  recognize those names. The files were classified as `unclassified`,
  `normalized/hill_score_daily.json`, `endurance_score_daily.json`, and
  `vo2max_daily.json` were always empty, and the three families reported
  `SKIPPED_NOT_PRESENT` with no warning. One-shot `run-all` was not affected.

## Output changes

Rerun `snapshot run-all` after upgrading. Compared with v1.7.0 output from the
same Snapshot Store:

- `normalized/hill_score_daily.json`, `endurance_score_daily.json`, and
  `vo2max_daily.json` contain the merged rows, and
  `analysis/performance_metrics_daily.csv` contains the Hill Score and
  Endurance Score rows.
- In `run_summary.json`, `START_HERE.md`, and `DATASET_INVENTORY.md`, the
  `hill_score`, `endurance_score`, and `vo2max` families report `PROCESSED`
  with their record counts instead of `SKIPPED_NOT_PRESENT`. `run_manifest.json`
  lists the three merged files under these families instead of
  `unclassified`.
- The record counts in `qa/`, the corresponding audit records, and
  `diagnostics/run_quality.json` include the new rows, and the run-level
  digests change with them. A Support Bundle made from the output carries the
  new `run_quality.json` counts.
- `diagnostics/source_completeness.json`, which describes the registered
  Exports, and the `doctor --run-output` findings are unchanged.
- Endurance Score values that differ across Snapshots are still kept as
  observed variants in `audit/endurance_score_daily.json` and stay out of the
  normalized rows, as before.

One-shot `run-all` output from the same Export is unchanged apart from
`product_version` `1.7.1` and the digests that include it. `snapshot
build-input` output is unchanged apart from `parser_version` `1.7.1` and the
digests that include it.

`validate-handoff`, `doctor --run-output`, and `support-bundle` accept an
output that contains `diagnostics/` only when the installed version produced
it, so rerun Run-All for outputs produced by v1.7.0 or earlier before using
these commands with v1.7.1.

## Also included

These internal changes toward v2.0.0 add no user-facing feature:

- `run_all` and `parse_fit_export` accept an optional keyword-only progress
  callback. The CLI passes no callback, and the output is the same with and
  without it.
- `validate-handoff`, `doctor --run-output`, and `support-bundle` accept
  Product major version 1 and later, and the Support Bundle Run Quality check
  accepts pre-release versions such as `2.0.0rc1`. The rule above for outputs
  that contain `diagnostics/` is unchanged.
- The wheel contains an internal `gui` package and its page files. The GUI is
  in development for v2.0.0; there is no `gui` command, and it is not
  supported for use in this release.
- The Windows CI job now fails when any command in a multi-line step fails.

## Compatibility

- The 17 datasets, 224 fields, 6 relationships, stable keys, and output paths
  are unchanged.
- The Snapshot lifecycle contract and policy registry versions remain `v1.0`.
  Existing Snapshot Stores load and verify without migration.
- The Product exit mapping remains `PASS -> 0`,
  `PASS_WITH_WARNINGS -> 0`, `PARTIAL_SUCCESS -> 3`, and `Fatal -> 2`.
- `PARTIAL_SUCCESS` / exit 3 is a completed result with bounded FIT exclusions,
  not a Fatal result.
- CLI commands and options are unchanged.

See [Known Limitations](../known_limitations.md#snapshot-lifecycle) and the
[Migration Notes](../migration_notes.md).

## Install

```bash
python -m pip install garmin-running-data-normalizer==1.7.1
garmin-running-data-normalizer --version
```
